## 🚀 Quick Start

### 1. Setup Environment
```bash
# Create .env.local with:
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key
ANTHROPIC_API_KEY=sk-ant-your-key
```

### 2. Setup Database
Execute in Supabase SQL Editor (in this order):
1. `PROFILE_SCHEMA.sql`
2. `ROADMAP_SCHEMA.sql`
3. `QUIZ_SCHEMA.sql`
4. `RESOURCES_SCHEMA.sql`
5. `PROGRESS_SCHEMA.sql`
6. `PLANNER_SCHEMA.sql`

### 3. Run Server
```bash
npm install
npm run dev
# Visit http://localhost:3000
```

### 4. Test Integration
```bash
curl http://localhost:3000/api/integration/status
```

## 📚 Module Details

### Student Profile
- Stores: name, branch, year, interests, skills, career goal, learning style, budget, study hours
- **Routes:** `GET/POST /api/profile`
- **Service:** `lib/supabase/profile.ts`

### Claude API
- Model: Claude Opus 5 (latest)
- Max tokens: 1024 per request
- Error handling: 401, 429, 400, 500
- **File:** `lib/claude.ts`

### Prompt Builder
- 7 specialized prompt builders
- Tone: encouraging, formal, casual, friendly
- Detail: concise, balanced, detailed
- **File:** `lib/prompt-builder.ts`

### Personalized Chat
- Real-time conversation with profile context
- Personalized responses
- **Route:** `POST /api/chat`
- **File:** `app/api/chat/route.ts`

### Roadmap Generator
- 3-phase roadmaps (beginner, intermediate, advanced)
- Each phase includes: topics, milestones, projects, resources, practice
- Generated by Claude based on profile
- **Route:** `POST /api/roadmap/generate`
- **Service:** `lib/supabase/roadmap.ts`

### Daily Planner
- Breaks roadmaps into daily tasks
- Task types: study, practice, project, quiz, milestones
- Tracks completion status
- **Routes:** 
  - `POST /api/planner/generate`
  - `GET /api/planner/today`
  - `GET /api/planner/upcoming`
  - `POST/GET /api/planner/task`
- **Service:** `lib/planner/planner-service.ts`

### Quiz Generator
- Question types: MCQ, Coding, Short Answer
- Difficulty: easy, medium, hard
- Adaptive to roadmap stage
- **Route:** `POST /api/quiz/generate`
- **Service:** `lib/supabase/quiz.ts`

### Resource Recommendation
- 30+ curated resources (verified quality)
- Types: Documentation, YouTube, GitHub, Courses, Practice, Books
- Filtered by: career goal, skill level, roadmap stage, topic
- **Route:** `POST /api/resources/recommend`
- **Service:** `lib/resources/recommendation-service.ts`

### Progress Tracking
- Tracks: topics, quizzes, projects, roadmap items
- Metrics: overall %, roadmap %, streak, weekly breakdown
- **Routes:**
  - `POST /api/progress/topic`
  - `POST /api/progress/quiz`
  - `POST /api/progress/project`
  - `POST /api/progress/roadmap-item`
  - `GET /api/progress/summary`
- **Service:** `lib/progress/progress-service.ts`

### Integration Layer
- Orchestrates all modules
- Provides unified dashboard
- Next step recommendations
- **Routes:**
  - `GET /api/integration/status`
  - `GET /api/integration/dashboard`
- **Service:** `lib/integration/orchestrator.ts`

## 🎓 Example Usage Flow

### Day 1: User Onboarding
```bash
# 1. Complete profile
POST /api/profile
{
  "name": "John",
  "branch": "CSE",
  "year": "2nd",
  "skills": ["JavaScript", "HTML"],
  "interests": ["Web Development"],
  "careerGoal": "frontend",
  "learningStyle": "hands-on",
  "monthlyBudget": 500,
  "dailyStudyHours": 2
}

# 2. Chat with AI
POST /api/chat
{
  "message": "What should I learn?"
}
Response: "Based on your profile..."
```

### Day 2-3: Learning Setup
```bash
# 1. Generate roadmap
POST /api/roadmap/generate
{
  "topic": "React"
}
Response: {beginner, intermediate, advanced phases}

# 2. Create daily plan
POST /api/planner/generate
Response: Daily tasks from roadmap

# 3. Check today's tasks
GET /api/planner/today
Response: [task1, task2, task3]
```

### Day 4+: Learning
```bash
# 1. Get today's tasks
GET /api/planner/today

# 2. Study and record progress
POST /api/progress/topic
{"topic": "React Hooks", "timeSpentMinutes": 45}

# 3. Take quiz
POST /api/quiz/generate
{"topic": "React", "difficulty": "medium"}

# 4. Submit quiz
POST /api/progress/quiz
{"quizId": "...", "score": 85}

# 5. Get resources
POST /api/resources/recommend
{"topic": "React"}

# 6. Check progress
GET /api/progress/summary
Response: {overall_completion_percentage, streak, weekly_progress}

# 7. Get dashboard
GET /api/integration/dashboard
Response: {complete learning state}
```
